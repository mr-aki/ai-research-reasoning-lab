# Research Methodology

This lab treats AI engineering as an empirical discipline.

## Experimental loop

1. Define a falsifiable question.
2. Select a baseline.
3. Define evaluation cases and metrics before running.
4. Run the baseline.
5. Run the intervention under the same conditions.
6. Record configuration, latency, cost and failures.
7. Analyze regressions and unexpected behavior.
8. Repeat when randomness or external model behavior matters.
9. Publish limitations.

## Integrity rules

- Never fabricate benchmark results.
- Never report an experiment that was not run.
- Never hide a failed experiment.
- Separate measured results from hypotheses.
- Record model versions and configuration where relevant.
