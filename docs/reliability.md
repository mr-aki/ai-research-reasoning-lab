# Reliability Strategy

Reliability is a stack, not a single accuracy number.

### Grounding
Track which evidence supports each answer.

### Verification
Use independent checks where practical and abstain when support is insufficient.

### Contradiction detection
Compare claims and evidence for conflicts.

### Calibration
Measure whether confidence corresponds to observed correctness.

### Failure analysis
Keep representative failures, categorize them, and turn recurring failures into regression tests.

### Reproducibility
Store experiment configuration, seeds where applicable, dependency versions and evaluation definitions.

The project will not claim production-grade reliability until the relevant tests and real measurements exist.
