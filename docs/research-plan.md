# Research Program

The project is designed to evolve through controlled experiments rather than a single giant demo.

## Research questions

### RQ1 — Does retrieval improve grounded answer quality?
Compare no retrieval, lexical retrieval, hybrid retrieval and reranking on the same evaluation set.

### RQ2 — Does independent multi-agent critique reduce unsupported claims?
Measure unsupported-claim rate and task accuracy against a single-agent baseline.

### RQ3 — When does verification justify abstention?
Measure correctness, coverage and calibration while varying verification thresholds.

### RQ4 — What is the cost of reliability?
Measure latency and model/tool cost against quality and failure reduction.

### RQ5 — Does adaptive routing outperform fixed routing?
Compare routing policies under equal task distributions and resource budgets.

## Publication standard

An experiment is only considered complete when its setup, baseline, metrics, measured results, failures and limitations are recorded.
